## Before submission

- Complete [group_members.txt](./group_members.txt) with every group member's name and roll number.
- Run each `main.py` using the command shown in its lab report.
- Capture genuine screenshots of each program running and save them in that lab's `screenshots` folder. The folders contain instructions only; no screenshots are fabricated or included.
- Check that your instructor accepts the sample problem/data used in each experiment, and add or revise material if a specific format or dataset was assigned.
- Submit this complete folder through Google Classroom. Only one group member needs to submit it.

## Running a lab

Open a terminal in the relevant lab folder and run:

```text
python main.py
```

If your system uses the Python launcher, use `py main.py`.
